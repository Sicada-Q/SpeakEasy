# SpeakEasy · 真人感英语口语陪练（WorkBuddy 技能）

把 WorkBuddy 对话变成一位「外国同事 / 语伴」：你用英语说/写一句，它就用母语者口吻回你 1–4 句自然的职场日常英语，并顺手把你这句的语法、拼写、用词、语气问题揪出来，给出「原句 → 地道改法 → 一句讲解」。

- **零配置**：直接用 WorkBuddy 自带模型，不需要任何 API Key、不开任何外部链接。
- **自动进入**：你用英语搭话，或说「练习口语 / 口语模式 / speak English practice」时自动开启；说「退出口语模式 / 正常模式」退出。
- **地道优先**：回复像真人在办公室会说的话——缩略、口语习语、自然节奏，绝不写成范文。
- **边说边纠**：每句都私下审一遍，只点真问题，没问题就夸你。

## 场景

`换场景：开会 / 站会 / 客户 / 闲聊 / 一对一 / 社交 / 新人 / 跟进` 可随时切换语境。

## 安装

**方式 A：克隆**
```bash
git clone https://github.com/<你的用户名>/SpeakEasy.git ~/.workbuddy/skills/SpeakEasy
```

**方式 B：手动**
把本仓库的 `SKILL.md` 放到 `~/.workbuddy/skills/SpeakEasy/SKILL.md` 即可。

## 使用

| 你说 | 效果 |
|---|---|
| 直接用英语搭话 | 自动进入陪练，母语者口吻回复 + 纠错 |
| 「练习口语 / 口语模式」 | 显式开启陪练 |
| 「换场景：开会」 | 切换语境 |
| 「多纠一点 / 严格模式」 | 把轻微不地道也点出来 |
| 「退出口语模式 / 正常模式」 | 结束陪练，恢复常规 |

> 本技能是纯文字陪练（回复与纠错都是文字，不发语音）。想听真人发音 / 按住说话，可在 WorkBuddy 内置预览打开本地语音版。
