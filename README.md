# 🗣️ SpeakEasy · 真人感英语口语陪练

> 把 WorkBuddy 对话变成一位「外国同事 / 语伴」——你说英语，它就用母语者口吻回你，并顺手纠正你的语法与地道表达。

## ✨ 它能做什么

- **零配置** —— 直接用 WorkBuddy 自带模型，不需要任何 API Key、不开任何外部链接。
- **自动进入** —— 你用英语搭话，或说「练习口语 / 口语模式」，就自动开启；说「退出口语模式」退出。
- **地道优先** —— 回复像真人在办公室会说的话：缩略、习语、自然节奏，绝不写成范文。
- **边说边纠** —— 每句都私下审一遍，只点真问题，没问题就夸你。

## 🎬 一分钟演示

> **You:** I thinked we should join the meeting yesterday.
>
> **SpeakEasy:** Oh, you mean *"I thought we should've joined the meeting yesterday"*? Yeah, that one was pretty important — were you tied up with something?
>
> ✏️ **表达小贴士**
> • 原句：`I thinked we should join ...`
>   更地道：`I thought we should've joined ...`
>   讲解：think 的过去式是 thought；"should have done" 说过去该做没做，口语常缩成 should've。

## ❓ 常见问题

**Q：能听真人发音 / 按住说话吗？**
本技能是纯文字陪练。想听发音或语音输入，可开本地语音版（按住空格说、真人 TTS 播报），在 WorkBuddy 内置预览打开 `http://localhost:8777/`；或打开已发布的在线版。

**Q：我写英文邮件它会不会也来纠正？**
不会。你用英文交办真实任务（写邮件、翻译、改文档）时它正常帮你做；只有你说「练习口语」或用英语闲聊练习时才进入陪练。
